Tette delle monache：歴史・起源・伝統

空気でできているかのように軽いスポンジのドーム、中にはクリーム、そして小さな雪山のように見せる粉砂糖。イタリア・プーリア州アルタムーラでいちばんユニークなこのお菓子には、修道院、大切に守られたレシピ、そして思わず笑みがこぼれる名前の物語があります。

Tette delle monache とは

Tette delle monache は、スポンジケーキに似た生地で作る小さなドーム形のお菓子です。ただしスポンジよりずっと軽く、卵をじっくり泡立ててごく少量の小麦粉を加え、オーブンで雲のようにふくらませます。形は丸く、てっぺんに小さな突起があります。

冷めたらカスタードクリームやシャンティイクリーム（ホイップクリームで軽く仕上げたカスタード）を詰め、たっぷりの粉砂糖をかけて完成です。外はさっくり軽く、中はしっとりクリーミー。その繊細なコントラストが魅力です。

プーリアでは、日曜日の家族のランチのあとに食卓に並ぶお菓子のトレー guantiera（グアンティエーラ）の定番。アルタムーラの菓子店では一年中手に入ります。

起源：アルタムーラのクララ会修道女

イタリアの多くのお菓子と同じように、このお菓子も修道院の壁の内側で生まれました。伝承では、tette delle monache はアッシジの聖クララが創設した女子修道会、クララ会の修道女たちと結びつけられています。プーリアやアブルッツォのクララ会修道院は、何世紀にもわたって本格的な菓子工房でもありました。

アルタムーラでゆかりの地とされるのは、旧市街の中心にある聖クララ修道院です。町に伝わる話によれば、禁域で暮らす修道女たちが代々オリジナルのレシピを守ってきました。今もこの修道院は、アルタムーラの味を訪ねる旅人の立ち寄りスポットになっています。

正確な年代や考案者の名前は伝わっていません。修道院のレシピによくあるように、物語は修道女から修道女へと受け継がれ、やがて町の菓子店へと広まりました。こうした伝説めいた背景も、このお菓子の魅力のひとつです。

なぜ「tette delle monache」と呼ばれるのか

イタリア語で直訳すると「修道女の胸」。思わずくすっと笑ってしまう、遊び心のある名前です。いちばんわかりやすい理由はその形で、てっぺんに突起のある柔らかなドームが、率直に言えば胸を思わせます。それを修道女と結びつけるところに、聖と俗が軽やかに混ざり合う南イタリアの菓子らしい、庶民のユーモアが感じられます。

これは珍しいことではありません。たとえばシチリアには聖アガタの minne（ミンネ）など、同じく大胆な名前を持つ修道院菓子があります。もっと控えめな名前を好む地域では、単に sospiri（ソスピーリ、「ため息」の意）と呼ばれています。

いとこのお菓子：sise と sospiri

Tette delle monache には、イタリアのほかの地域に近い親戚がいます。おそらく同じ修道院の伝統から生まれたものです。

Sise delle monache

アブルッツォ州グアルディアグレーレの名物。同じくふんわりしたスポンジとクリームですが、3つの「ドーム」がつながった形です。

Sospiri

プーリア各地、たとえばビシェーリエで親しまれているお菓子。生地は似ていますが、粉砂糖ではなく砂糖のアイシングで覆われています。

Tette delle monache

アルタムーラ版。突起のある単独のドームにクリームを詰め、粉砂糖で雪化粧したような姿です。

ほかの呼び名

同じお菓子でも、町や菓子店、語り手によって名前が変わります。主な呼び名は次のとおりです。

  • Tette delle monache または tette della monaca：アルタムーラとプーリア全体でいちばん知られた名前。
  • Sospiri または sospiri pugliesi：多くの菓子店で使われる控えめな名前（アイシング版を指すこともあります）。
  • Sise delle monache：アブルッツォ州での呼び名で、グアルディアグレーレの名物。
  • Seni delle monache、minne、zinne delle monache：同じ言葉遊びの地方版・口語版。
  • Dolce delle monache di Altamura または dolce delle Clarisse：修道院発祥であることを伝える呼び名（「アルタムーラの修道女のお菓子」「クララ会のお菓子」）。

日本では「イタリア 修道院菓子」「プーリア 伝統菓子」「アルタムーラ お菓子」「ソスピーリ」などで検索されることもあります。どんな言葉で呼ばれても、お菓子はひとつ。中にクリーム、上に粉砂糖をのせた、アルタムーラのふんわりドームです。

パンとお菓子の町、アルタムーラ

アルタムーラはムルジャ高原の上、バーリから約45キロの場所にある町です。世界的には何よりDOPのパンで知られ、これはヨーロッパで初めて原産地名称保護（DOP）を受けたパンです。町には皇帝フリードリヒ2世が建てさせた見事な大聖堂、路地と claustri（クラウストリ）と呼ばれる中庭が入り組んだ旧市街、そしてヨーロッパで最も重要な先史時代の発見のひとつ「アルタムーラ人」もあります。

かまどと小麦のこの土地で、tette delle monache は伝統の甘い一面。町を訪れたあとに持ち帰りたい、いちばんおいしいお土産です。

楽しみ方と保存方法

  • できたてがいちばん：外側がまだ軽くさっくりしている、作ってから数時間がベストです。
  • 冷蔵保存：クリーム入りなので涼しい場所で保存し、1〜2日以内にお召し上がりください。
  • 粉砂糖は最後に：できれば食べる直前にかけると、白さを保ち、溶けません。
  • コーヒーと一緒に：朝食にも食後にも、エスプレッソと相性抜群。夏はアイスコーヒーとどうぞ。

よくある質問

Tette delle monache とはどんなお菓子ですか？

イタリア南部プーリア州アルタムーラの伝統菓子です。とても軽いドーム形のスポンジ生地にカスタードクリームやシャンティイクリームを詰め、粉砂糖をかけて仕上げます。

なぜ tette delle monache という名前なのですか？

イタリア語で直訳すると修道女の胸という意味で、てっぺんに小さな突起がある丸い形と、修道院とのつながりに由来します。特にクララ会の修道女たちがこのレシピを生み、代々守ってきたと伝えられています。

発祥地はどこですか？

プーリアの伝承では、アルタムーラと旧市街にある聖クララ修道院と結びつけられています。アブルッツォ州グアルディアグレーレには、よく似たお菓子 sise delle monache があります。

どのように保存すればよいですか？

クリームが入っているため冷蔵庫で保存し、できれば1〜2日以内に新鮮なうちに召し上がってください。粉砂糖は食べる直前にかけるのがおすすめです。

ほかにどんな呼び名がありますか？

tette della monaca、sospiri（ソスピーリ）や sospiri pugliesi、sise delle monache（アブルッツォでの呼び名）、seni delle monache、また口語では minne や zinne delle monache とも呼ばれます。

sospiri との違いは何ですか？

どちらも親戚のようなお菓子です。sospiri は生地が似ていますが、砂糖のアイシングで覆われています。一方、tette delle monache には粉砂糖がかかっています。
