Tette delle monache：历史、起源与传统

一个轻得仿佛由空气做成的海绵蛋糕圆顶，一颗奶油做的心，再撒上一层糖粉，看起来就像一座覆雪的小山。它是意大利普利亚大区阿尔塔穆拉最有趣的甜点，背后有修道院、秘传食谱，还有一个让人会心一笑的名字。

Tette delle monache 是什么

Tette delle monache 是一种小巧的圆顶甜点，面糊类似海绵蛋糕，但更加蓬松：鸡蛋长时间打发，面粉极少，在烤箱里膨胀得几乎像一朵云。外形圆润，顶部有一个小尖。

冷却后，在里面填入卡仕达酱或香缇奶油（加入打发鲜奶油的卡仕达酱），最后撒上厚厚一层糖粉。口感对比十分细腻：外层干爽轻盈，内里柔软绵密。

在普利亚，它是周日 guantiera 的经典之选，也就是家庭午餐后端上桌的那一盘糕点。在阿尔塔穆拉的甜品店里，一年四季都能买到。

起源：阿尔塔穆拉的圣嘉兰修女

和许多意大利甜点一样，它也诞生于修道院的高墙之内。传统上认为 tette delle monache 出自圣嘉兰修女会，这是由亚西西的圣嘉兰创立的女修会。数百年来，普利亚和阿布鲁佐的修道院就是名副其实的甜点作坊。

在阿尔塔穆拉，人们提到的是老城中心的圣嘉兰修道院。据城中流传的说法，隐修的修女们世代守护着最初的食谱。直到今天，这座修道院仍是来阿尔塔穆拉寻味的游客必到之处。

确切的年代和发明者的名字早已无从考证：和许多修道院食谱一样，这段历史在修女之间口口相传，最后才走进甜品店。正是这层传说的色彩，构成了它魅力的一部分。

为什么叫“tette delle monache”

这个意大利语名字字面意思是修女的乳房，本就带着幽默的意味。最直接的解释是它的外形：柔软的圆顶加上顶端的小尖，让人一看就联想到乳房。再把它和修女联系起来，更添了一份意大利南部许多甜点特有的民间幽默，神圣与世俗轻松地交织在一起。

这并非孤例：例如在西西里岛，就有圣阿加莎的 minne，以及其他名字同样大胆的修道院甜点。在许多地方，喜欢更含蓄叫法的人干脆称它为 sospiri（意为“叹息”）。

甜点表亲：sise 与 sospiri

Tette delle monache 在意大利其他地区还有几位近亲，它们很可能源自同一修道院传统：

Sise delle monache

阿布鲁佐大区瓜尔迪亚格雷莱镇的特产：同样松软的海绵蛋糕和奶油馅，但由三个“圆顶”连在一起。

Sospiri

在普利亚各地都很常见，例如比谢列：面糊相似，但表面裹的是糖霜淋面，而不是糖粉。

Tette delle monache

阿尔塔穆拉的版本：单个带尖的圆顶，内有奶油馅，表面的糖粉让它看起来像覆了一层雪。

其他名称

同一款甜点，会因城镇、甜品店和讲述者的不同而换个名字。最常见的叫法有：

  • Tette delle monache 或 tette della monaca：在阿尔塔穆拉和整个普利亚最为人熟知的名字。
  • Sospiri 或 sospiri pugliesi：较为含蓄的叫法，很多甜品店都在用（有时专指淋面款）。
  • Sise delle monache：阿布鲁佐大区的叫法，瓜尔迪亚格雷莱镇的特产。
  • Seni delle monache、minne 或 zinne delle monache：同一文字游戏的地方及民间变体。
  • Dolce delle monache di Altamura 或 dolce delle Clarisse：意为“阿尔塔穆拉修女甜点”“嘉兰会甜点”，强调其修道院渊源。

在中文网络上，人们常用“意大利修女甜点”“阿尔塔穆拉奶油甜点”“普利亚甜点”或“意大利 sospiri”来搜索它。无论叫什么，甜点都是同一个：来自阿尔塔穆拉的松软圆顶，内有奶油，外覆糖粉。

阿尔塔穆拉：面包与甜点之城

阿尔塔穆拉坐落在穆尔贾高原上，距巴里约 45 公里，以其DOP 面包闻名世界，这是欧洲第一款获得原产地名称保护（DOP）认证的面包。城里还有腓特烈二世下令修建的壮丽主教座堂，有由小巷和被称为 claustri 的庭院构成的老城区，以及著名的“阿尔塔穆拉人”化石，它是欧洲最重要的史前发现之一。

在这片烤炉与麦田的土地上，tette delle monache 是传统中甜蜜的一面，也是游览这座城市后最值得带走的美味纪念品。

品尝与保存

  • 新鲜最好：刚做好的几个小时里口感最佳，外层依然轻盈干爽。
  • 需要冷藏：由于内有奶油馅，应冷藏保存，并在一到两天内食用。
  • 糖粉最后撒：如有可能，上桌前再撒糖粉，这样它会保持洁白，不会融化。
  • 搭配咖啡：无论早餐还是饭后，配一杯意式浓缩咖啡都很完美，夏天则可以配一杯冰咖啡。

常见问题

Tette delle monache 是什么？

它是意大利南部普利亚大区阿尔塔穆拉的传统甜点：一个极其轻盈的圆顶海绵蛋糕，夹有卡仕达酱或香缇奶油，表面撒满糖粉。

为什么叫 tette delle monache？

这个意大利语名字字面意思是修女的乳房，既指它圆润且顶端带一个小尖的外形，也指它与修道院的渊源，尤其是圣嘉兰修女会。相传正是修女们创造并世代守护了这份食谱。

它起源于哪里？

普利亚的传统将它与阿尔塔穆拉以及老城区的圣嘉兰修道院联系在一起。阿布鲁佐大区瓜尔迪亚格雷莱镇有一款非常相似的甜点，名为 sise delle monache。

应该如何保存？

由于内有奶油馅，需要冷藏保存，并尽量新鲜食用，最好在一到两天内吃完。糖粉最好在上桌前再撒。

它还有哪些别名？

它也被称为 tette della monaca、sospiri 或 sospiri pugliesi、sise delle monache（阿布鲁佐叫法）、seni delle monache，民间口语中还叫 minne 或 zinne delle monache。

它和 sospiri 有什么区别？

两者是近亲：sospiri 的面糊相似，但表面裹的是糖霜淋面；而 tette delle monache 表面撒的是糖粉。
